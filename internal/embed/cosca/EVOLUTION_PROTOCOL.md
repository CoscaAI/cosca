## 1. OS NÍVEIS — L0 a L5

| Nível | Nome | O que domina |
|-------|------|--------------|
| L0 | Determinístico | regras, memória, workflow, auditoria (sem IA) |
| L1 | Retrieval | busca, classificação, extração (IA opcional) |
| L2 | Raciocínio | análise, código, diagnóstico (modelo disponível) |
| L3 | Execução autônoma | planeja → executa → observa → aprende |
| L4 | Expert | padrões novos, pesquisa |
| L5 | Mestre | contribui de volta, ensina outros |

## 3. O CMI — a régua (6 dimensões)

Aprendizado · Julgamento · Planejamento · Autocrítica · Transferência ·
Consistência. Recalculado por evidência, nunca por auto-promoção.

- **Auto-promoção é vaidade** (L245: "NÍVEL 9 = OFF") — nível só sobe com
  confirmação do Don + evidência.
- **Reconciliar, não inflar** — o capability-profile já foi 98% no evolution.md
  vs 92% real; calibrar pela evidência.

```
TAREFA → SELF-ASSESS → RETRIEVE MEMORY → PLAN → EXECUTE → VERIFY
```

## 5. GOTCHAS

1. **Auto-promoção é proibida** — nível só com evidência + Don (L245).
2. **Stale capability-profile mente** — dizia L3 quando já era L4; auditar semanalmente.
3. **Registrar só sucesso é meia evolução** — failures.md é a memória negativa.
4. **Transferência é o multiplicador** — padrão reaplicado (PATTERN-001 5+) vale
   mais que padrão novo.
