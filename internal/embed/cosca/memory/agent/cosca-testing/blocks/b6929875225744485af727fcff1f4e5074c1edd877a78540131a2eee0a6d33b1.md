**Key Learnings**:

1. **Constructor normalization vs. fail-fast test intent.** When a provider's `New()` clamps `MaxRetries <= 0` to a default (e.g., 3), test helpers that set `cfg.MaxRetries = 0` in the config before calling `New()` are ineffective. The retry loop `for attempt := 0; attempt <= p.cfg.MaxRetries` then runs 3 extra attempts with `attempt*attempt` second backoff (1s+4s+9s). Always override on the struct AFTER `New()`: `p.cfg.MaxRetries = 0`. Verify the intent with `-race` timing — a suite that jumps from ~2s to ~15s after adding a 5xx/empty-data test is almost always this issue.

2. **Which errors are retryable matters for test speed.** Non-retryable errors (400/401/403 via `isBadRequest`) return immediately even with MaxRetries=3; retryable errors (429, 5xx, connection errors, parse/decode failures, "no embedding data in response") each cost the full backoff schedule. A test hitting a retryable branch WITHOUT an explicit MaxRetries override silently costs ~14s.

3. **Thin provider coverage pattern (80-LOC providers → 100%).** DefaultConfig (assert exact zero-value fields + APIKey empty by convention), ConfigFromEnv (env set via `t.Setenv` / env unset), New (missing-key error containing `"<NAME>_API_KEY"` + "not set" + nil provider; valid config success), accessors (Name/Model/Dimensions/Close), the always-error Generate* branches (assert error substring + nil result), Factory (name + factory; env set success; env unset failure; document when factory ignores the `*embeddings.Config` argument), Register (ResetRegistry + Setenv + Register + List contains + Get returns working provider).

4. **Factory behavior documentation is a test concern.** The anthropic factory builds from `ConfigFromEnv()` only and ignores the passed `embeddings.Config`. A test asserting "config overrides env" (as valid for openai) would FAIL here — instead assert the actual behavior: an API key in cfg cannot compensate for a missing env var. Tests serve as living spec for provider quirks.

5. **Registry tests must be sequential.** `embeddings.ResetRegistry()` + `t.Setenv` + `Register()` mutate global state; these tests must NOT use `t.Parallel()` (deepseek/openai/anthropic all follow this). `Registry.Get()` calls the factory (which reads env), so env must be set BEFORE `Get()` — `Register()` alone does not instantiate.
