**Key Learnings**:

1. **Workflows handlers need no mocks.** `workflows.NewManager(t.TempDir())` loads ~37 embedded workflows deterministically; `mgr.Add(workflow)` adds a deterministic 1-step workflow. With no StepRunner, `Run` simulates steps at 10ms each — 1 step keeps tests fast. `Search`/`Get`/`Run` are case-insensitive (lowercase map keys). The `RunStream` handler reads `r.PathValue("name")` — set it via `req.SetPathValue("name", ...)`.

2. **RunStream error paths are in-band SSE events, not HTTP errors.** Workflow-not-found writes `data: {"type":"error",...}` via `sw.WriteError` and returns — the HTTP status stays 200. Only nil-mgr (503) and empty-name (400) are real HTTP errors. A `workflow_failed`/`workflow_completed` hub broadcast happens on the success/error paths — the hub must be `Shutdown` in cleanup.

3. **Memory engine is a real multi-layer store, not an in-memory stub.** `Store` writes md files + SQLite FTS5 index; `Search` uses `MATCH` (empty query returns recent records); `Retrieve` enforces TTL expiry (a record with past CreatedAt + 24h TTL returns 404 via the Get handler). `Promote` session→project works; promoting to an unknown layer ("bogus") returns "no store for target layer" → 500. `Delete` on a missing record returns nil from the engine (idempotent) but the handler 404s earlier at the `Retrieve` pre-check.

4. **BUG (documented, not fixed): `MemoryHandler.Store` nil-deref on error path.** `handler/memory.go:134` — when `h.engine.Store` returns `(nil, err)` (e.g., unknown layer like "bogus"), the error branch dereferences `saved.ID` → panic. Reproducible with `POST /v1/memory/store` + `layer=bogus`. Do NOT write a test that triggers it (panic fails the suite); document instead.

5. **Secrets handler success paths need a real vault.** `secrets.New(filepath.Join(t.TempDir(), "secrets.db"), testJWTSecret)` creates an AES-GCM encrypted SQLite vault. `Set` is upsert (preserves created_at, refresh updated_at); `Get` decrypts; `Delete` returns `ErrSecretNotFound` when rows==0 (→ 404), and requires `confirm_key` matching the path key (mismatch → 400). `List` never exposes values. `created_by` defaults to "system" without auth claims.

6. **`httptest.ResponseRecorder` implements `http.Flusher`**, so `NewSSEWriter` succeeds on it. To cover `NewSSEWriter`'s "streaming not supported" branch, define a minimal `http.ResponseWriter` struct WITHOUT a `Flush()` method (record `status` + `body` fields for assertions).
