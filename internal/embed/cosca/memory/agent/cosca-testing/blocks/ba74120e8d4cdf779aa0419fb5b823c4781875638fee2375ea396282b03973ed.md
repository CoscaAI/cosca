| **Learned** | (1) No Windows `f.Sync()` em handle O_RDONLY → ERROR_ACCESS_DENIED ("Acesso negado"): FlushFileBuffers exige handle com escrita. Fix: abrir temp com O_CREATE\|O_TRUNC\|O_WRONLY, Write→Sync→Close→Rename. (2) `filepath.IsAbs("/etc")` é false no Windows — testes com semântica POSIX devem skip com justificativa. (3) Paths de documento usados como chaves lógicas (ex.: "docs/a.md") DEVEM usar pacote `path`, não `path/filepath` — barra invertida quebra lookup de map no Windows; saída idêntica no Linux. (4) Granularidade do clock Windows (dois time.Now() consecutivos podem diferir em 0) faz time.Since() medir 0 para operações in-memory rápidas — asserções de timing `> 0` devem ser relaxadas para `>= 0`. (5) `os.Symlink` exige privilégio de admin no Windows — skip se a criação falhar. (6) chmod 0o000 não torna arquivo ilegível no NTFS — guard de permissões POSIX com `runtime.GOOS != "windows"`. (7) `COMSPEC` (cmd.exe) é o fallback de shell no Windows — testes que isolam SHELL devem limpar COMSPEC também. (8) Scripts shebang (#! /bin/sh) não executam no Windows — skip de testes com fake executável shell. (9) Paths de teste devem ser construídos com filepath.Join (separador nativo) para validar o comportamento real do fsnotify/ignore em ambos OSes. |
