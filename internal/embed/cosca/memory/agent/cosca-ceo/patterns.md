# cosca-ceo — Patterns

## P1 — Strategic Decision Template
**Quando usar**: Toda decisão estratégica.
**Padrão**: (1) cosca knowledge search → (2) consultar learnings → (3) consultar critic → (4) Constitution check → (5) decidir com evidência.
**Exemplo**: "Devemos migrar para microserviços?" → search "microservices migration" → learnings diz "evitar sem necessidade comprovada" → critic aponta custo de orquestração → Constitution: simplicidade → decisão: NÃO.

## P2 — Resource Allocation Matrix
**Quando usar**: Priorização de múltiplas iniciativas.
**Padrão**: Impacto (1-5) × Esforço (1-5) × Risco (1-5) × Alinhamento Estratégico (1-5). Ordenar por score total.
