| **Level** | 2 |
| **Outcome** | success |
| **Tags** | #coverage #compute-fabric #gap-triage #abc-classification #state-injection #race-condition |
| **Related** | `internal/compute/` package (backpressure.go, fabric.go, hardware.go, pool.go), coverage.out, ABC protocol |
| **Learned** | 1) ABC triage: 3 gaps testados (B), 7 gaps aceitos como defensivos (C), 0 dead code removido (A). 2) State injection via mutex-protected fields (e.g., `f.probe.mu.Lock(); f.probe.snapshot.LogicalCores = 0`) é eficaz para cobrir branches condicionais sem mockar /proc. 3) `// coverage: accept` é o padrão de documentação para gaps aceitos, posicionado na linha anterior ao block descoberto. 4) `runtime.NumCPU()` sempre retorna ≥1, então `if cores == 0` em `Start()` é unreachable — aceito como defensivo. 5) `/proc/loadavg` e `/proc/meminfo` readers em `hardware.go` têm 6 branches defensivas (erro de open, linhas vazias, campos insuficientes, parse error) que são impossíveis de testar em Linux sem mocking de sistema de arquivos. 6) `executeTask` default case no select de envio de resultado é unreachable porque o channel tem buffer=1 e só há um sender por channel — aceito como defensivo. 7) Para testar o double-Start guard, chamar `Start()` duas vezes consecutivas sem `Stop()` no meio. 8) Para testar `CircuitBreaker.IsOpen` default case, injetar `CircuitState(99)` via `cb.breakers["x"] = &poolBreaker{state: CircuitState(99)}`. 9) `go test -race -count=1` passa limpo em todas as funções, incluindo as com manipulação concorrente de mutex. |
| **What worked well** | `go tool cover -func` + `grep " 0$" coverage.out` para identificar blocos exatos descobertos. Classificação ABC clara e rápida. State injection sem modificar código de produção. |
| **What was difficult** | Cores==0 em `Start()` não é testável porque `Start()` chama `probe.Start()` que sobrescreve o snapshot com dados reais de hardware — não há janela de injeção sem race condition. Solução: aceitar como C. |
| **Improvement points** | 1) Considerar extrair leitura de /proc para uma interface mockável em refatoração futura (não aplicável agora pois não podemos modificar produção só para testar). 2) O padrão `// coverage: accept` deve ser searchável por scripts de CI para gerar relatório de gaps aceitos vs. não aceitos. |
| **Next** | Aplicar ABC triage para outros pacotes abaixo de 100%: `internal/runtime/`, `internal/llm/`, `internal/mcp/`, `internal/cache/`. |
