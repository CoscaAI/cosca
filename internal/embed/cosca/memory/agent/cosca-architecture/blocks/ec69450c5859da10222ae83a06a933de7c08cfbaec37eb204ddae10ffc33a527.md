### 2026-08-04 — Advisory memory integrity manifest

**Técnica**: Auditoria offline por inventário explícito e hashes SHA-256, com
manifesto JSON atômico e comando CLI separado do runtime.
**Domínio**: architecture, memory-governance, integrity, reversibility
**Nível**: 4 | **Outcome**: success

**O que foi aprendido**:

1. A fronteira mais segura para governança inicial é `cosca memory integrity`,
   reutilizando o CLI existente, mas executando fora da jaula e sem qualquer
   chamada no startup do runtime.
2. O manifesto deve ser um artefato plain JSON em `.cosca/audit/`, enquanto a
   lista protegida permanece explícita no verificador; assim o próprio
   manifesto não entra em ciclo de auto-hash e bancos/sessões não são tocados.
3. Mismatch deve ser observável (saída + status não-zero) sem enforcement:
   isso permite CI e revisão humana agora, preservando reversibilidade até uma
   futura decisão de bloqueio.

**Próximo passo**: calibrar a lista protegida e somente depois considerar
   integração com hook/CI ou bloqueio, mediante decisão de governança.
