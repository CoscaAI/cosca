### 2026-07-30 — F10.1 Cognitive Economics Engine design (ÁPICE da arquitetura cognitiva)

**Técnica**: Design do Cognitive Economics Engine — Platform ROI da arquitetura cognitiva inteira
**Domínio**: architecture, economics, platform-metrics, executive-dashboard
**Contexto**: Criação do F10.1 como engine de agregação econômica da plataforma, dependente de F2.1, F1.5, F7.1-F9.1, F8.1

**Aprendizados**:

1. **F10.1 é o CFO, não o caixa**: A distinção fundamental entre F2.1 (ROI por task — operacional) e F10.1 (Platform ROI — estratégico) é o insight arquitetural mais importante. F2.1 responde "esta task valeu a pena?". F10.1 responde "a plataforma valeu a pena hoje?". Um é extrato bancário, o outro é balanço patrimonial.

2. **Agregação de 7 engines sem criar dívida técnica**: F10.1 não cria novos dados — ele lê agregados que já existem em F2.1, F1.5 (B1-B5), F7.1, F7.2, F7.3, F9.1 e F8.1. O cálculo é pura aritmética sobre dados existentes, garantindo < 5s de execução.

3. **Tabela de precificação como linguagem universal**: Atribuir valor em dólar a ativos cognitivos (learning = $1, bug prevenido = $5, padrão reusado = $0.50) transforma métricas abstratas em linguagem de negócio que o Don entende instantaneamente.

4. **Dashboard executivo em 30s**: O formato do dashboard (receita vs custo, top/bottom contributors, alertas) segue o princípio de que o Don precisa entender a saúde econômica em 30 segundos. O relatório de 1 parágrafo é o formato ideal para consumo diário.

5. **10 alertas configuráveis com 4 níveis**: A separação P0-P3 com canais de notificação diferentes (don_immediate, dashboard, log) permite que o engine seja acionável sem ser ruidoso. O alerta de ROI < -50% é o "fire alarm" da plataforma.

6. **Exemplo real valida o design**: Com dados reais da Evolution Marathon (27 agentes, 8 ondas, 47 learnings, 150+ arquivos), o Platform ROI calculado foi +337.6% — cada $1 gerou $4.38. O exemplo demonstra que o modelo funciona com dados reais e produz insights acionáveis.

7. **Pipeline diário + semanal com automação completa**: A separação entre coleta (07:00 UTC), cálculo, comparação e relatório com schedule definido (diário 07:00, semanal segunda 08:00) garante que o engine opere sem intervenção manual.

8. **Relação F10.1-F2.1 é o padrão de agregação**: Este padrão de "engine operacional + engine de agregação estratégica" pode ser replicado em outros contextos (ex: F10.2 para governança, F10.3 para aprendizado).
