## Learning #2 — F1.5: Real Metrics Tracking (B1-B5) Implementado

**Date**: 2026-07-30
**Source**: Task F1.5 — Implementar tracking de métricas reais (B1-B5) do Cognitive Maturity Architecture
**Domain**: Observability, Cognitive Maturity
**Confidence**: 0.85

### Summary

Implementação completa da infraestrutura de tracking das 5 métricas reais de maturidade cognitiva (B1-B5) definidas na Seção 3 do COGNITIVE_MATURITY.md. Criados 7 arquivos: 1 especificação + 5 arquivos de tracking com dados de baseline + atualização do INDEX.md. Baseline extraído da análise completa de learnings.md (26 entradas, L1-L22).

### Key Findings

1. **B1 — Autonomia**: 20/26 tasks autônomas (76.9%). Streak atual de 12 tasks consecutivas sem intervenção desde o jail breach (L13). Única intervenção: L13 (cosca init --force sem DRY_RUN).

2. **B2 — Previsões**: 7/8 previsões corretas (87.5%). Acima da meta de 80%. Dois tipos de erro identificados: superestimação (viés de otimismo, B2-005) e subestimação (memória desatualizada, B2-006).

3. **B3 — Decisões Revertidas**: 1 reversão (jail breach L13). Categoria: bypass_governance. Cobertura de regras de proteção: 20% (1/5 categorias). 4 categorias aguardam implementação da Fase 1.

4. **B4 — Conhecimento Reutilizado**: 12 reusos documentados em 3 padrões: cross-agent-audit (3 reusos, L18→L19→L21), parallel-orchestration (5 reusos, Ondas 1-6), heuristics-applied (4 reusos, H-001 a H-020).

5. **B5 — Detecção Preventiva**: 5 detecções proativas: docs fictícios (K8s/PostgreSQL/Kafka), threshold crisis (4 valores conflitantes), permission paths stale, PostgreSQL fantasy cross-agent, MEMORY_MODEL.md drift (44 linhas). Proactive ratio: 50%. Lead time médio: semanas.

### Design Decisions

1. **Storage**: Arquivos markdown por métrica (não SQLite) — simplicidade, versionamento Git, legibilidade humana. Migração para SQLite na Fase 2.

2. **Collection**: Híbrido — manual pós-task (atual) com hook planejado no metacognition pipeline Stage 8 (Fase 2).

3. **Baseline**: Extraído de learnings.md via análise cross-reference. Cada entrada de métrica referencia o learning de origem para rastreabilidade completa.

4. **Dashboard**: Tabelas markdown + gráficos ASCII. Visualização rica planejada para Fase 2 (SQLite + cosca serve dashboard).
