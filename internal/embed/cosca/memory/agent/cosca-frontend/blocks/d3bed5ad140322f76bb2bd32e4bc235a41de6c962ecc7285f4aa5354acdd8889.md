| **Learned** | Framer Motion v11 `motion.div` has type conflicts with `React.HTMLAttributes<HTMLDivElement>` when spreading props: `onDrag`, `onDragEnd`, `onAnimationStart`, `onTransitionEnd` all have incompatible signatures between React DOM and Framer Motion. **Solution**: never spread `...props` from `HTMLAttributes` directly onto `motion.*` components. Instead, wrap motion content inside a plain `div` that receives the HTML spread, or use `Omit` on all conflicting event handlers. Also: `animate(motionValue, target)` has TS overload issues in v11 — use `useSpring` with `.set()` and `.on("change")` listener, or fall back to `requestAnimationFrame` for number animations. Added `shimmer` keyframes + `animate-shimmer` to tailwind config for ShimmerSkeleton. All 8 components compile with `tsc --noEmit` zero errors. |
