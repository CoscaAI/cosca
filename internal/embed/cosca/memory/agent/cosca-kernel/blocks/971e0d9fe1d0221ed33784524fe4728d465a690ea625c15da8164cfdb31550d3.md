Cognitive Recoverability: "consigo reconstruir a capacidade cognitiva
relevante a partir das fontes de verdade E demonstrar que a reconstrucao
satisfaz o contrato". Dimensoes: Code, Knowledge, Provenance,
Configuration, Semantic Space, Runtime, Integrity (as 7 cobertas).
Nao e "ter backup" — e reconstruir + VERIFICAR a identidade semantica.
