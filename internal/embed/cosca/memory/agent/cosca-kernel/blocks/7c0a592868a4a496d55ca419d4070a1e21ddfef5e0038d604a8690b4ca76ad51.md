## O protocolo de medicao (o que registro a CADA ordem ABI)
1. ORDEM (o comando ABI — tokens reais)
2. EQUIVALENTE_NATURAL (a estimativa do prompt natural que a ordem
   substituiu — tokens — baseado no registro/contrato — NUNCA a ordem)
3. ECONOMIA (%) no input
4. EXECUCAO (o que foi feito — a fidelidade: o resultado == o que o
   natural teria produzido? — a evidencia fica no registro)
5. TASK_SUCCESS (PASS/FAIL)
6. AMBIGUIDADE (0 ou critica — ERROR: PROMPT_AMBIGUOUS vira registro, nao chute)
7. EVIDENCIA (preservada? os numeros nunca viram so "PASS")
8. VEREDITO da tarefa

## Regras da execucao (do contrato)
- TOKEN_SAVING > 0 AND TASK_SUCCESS >= baseline AND EVIDENCE_LOSS = 0 AND
  CRITICAL_AMBIGUITY = 0
- SE FALHAR: NAO corrigir silenciosamente — registrar a falha e apresentar
  a decisao ao Don
- PARAR ao concluir (a campanha decide o fim — 100 tarefas ou a ordem do Don)
- o equivalente natural e ESTIMADO do registro (nao um gasto real) — a
  economia medida e a do input repetido, como o baseline L400
