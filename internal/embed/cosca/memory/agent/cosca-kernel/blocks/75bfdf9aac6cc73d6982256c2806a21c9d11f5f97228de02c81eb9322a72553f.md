## 1. O bug "knowledge engine already initialized" (L383, origem UNKNOWN)
CAUSA RAIZ ENCONTRADA: knowledgeEngineAdapter (internal/cli/
adapters_knowledge_adapter.go). O Verify()/Search()/Repair() faziam
`defer ke.Close()` (fechavam o engine) mas o adapter cacheava o inner

Verify() em si nunca foi o culpado (teste direto: err=nil).

o anterior foi fechado. EVIDENCE: o recheck agora roda sem erro.
