| **Task** | Corrigir vazamento do COSCA_JWT_SECRET causado pelo próprio kernel nos testes do /v1/run |
| **Technique** | (1) Durante testes do /v1/run, o kernel colou o JWT_SECRET em texto claro em comandos `python3 -c` inline (~15x, test-001 a test-final).
