## Metacognition Pipeline

Every task flows through: SELF-ASSESS → RETRIEVE MEMORY → PLAN STRATEGY → EXECUTE → VERIFY RESULT → CRITIQUE OWN WORK → EXTRACT PATTERN → UPDATE CAPABILITY MODEL

See: [workflows/metacognition-pipeline.md](../../../workflows/metacognition-pipeline.md)

## Distinction from cosca-critic

cosca-critic reviews individual DECISIONS (per-decision adversarial challenge).
cosca-paradigm reviews FOUNDATIONAL PATTERNS (long-term: "is this still the best approach?").

## Activation Gate

This agent requires ≥3 months of Confidence Model data before meaningful activation. Agent definition exists, but real paradigm questioning only begins when there's sufficient historical data to detect trends.
