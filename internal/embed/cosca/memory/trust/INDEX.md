## Como Usar Este Índice

### Para o Prediction Engine (F7.1)
```
Antes de delegar task de "testing":
  1. Consultar INDEX.md → cosca-testing é a melhor escolha (score 0.84)
  2. Verificar custo ($0.025) vs orçamento
  3. Verificar latência (14min) vs prazo
  4. Se aprovado: delegar. Se não: buscar alternativa (cosca-qa, 0.72)
```

### Para o Kernel (Pós-Task)
```
Após cada task:
  1. Calcular outcome, latency, cost, files_changed
  2. Adicionar entrada em TRUST_REGISTRY.md
  3. Recalcular reliability_score do agente
  4. Atualizar este INDEX.md
  5. Se agente caiu >0.10: notificar Don
```

### Para o Don (Gestão)
```
Revisão semanal:
  1. Verificar Top 5 — estão mantendo confiança?
  2. Verificar Declining — quais agentes precisam de tasks?
  3. Verificar Rising — reconhecer progresso
  4. Decidir: ativar novos agentes, ajustar manualmente, ou podar
```
