# EVOLUTION ENGINE — Self-Evolution & Capability Growth
- **Reports To**: Kernel
> **Version**: 1.0.0 | **Type**: kernel

## PURPOSE
Analyze codebase evolution, identify technical debt, and suggest improvements based on historical trends. Cross-references bug registry, learnings, and confidence model data.

## SCOPE
- Codebase analysis: complexity trends, coverage evolution, dependency health
- Technical debt identification: from code-quality/ and technical-debt/ metrics
- Improvement suggestions: prioritized by impact and effort
- NOT PR review — see cosca-review for per-PR checklist

## DISTINCTION
- cosca-review: per-PR immediate review
- cosca-evolution: broad temporal trend analysis (aggregate, historical)
