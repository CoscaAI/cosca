# Resource Resolver Engine

> Catálogo da coleção resource-resolver.

| File | Description |
|------|-------------|
| [SKILL.md](./SKILL.md) | Elimina paths hardcoded do Cosca: todos os componentes usam Virtual Paths resolvidos em runtime conforme o ambiente. |
| [environment.md](./environment.md) | Detecta o ambiente de runtime (OS, usuário, paths, capacidades) para informar a estratégia de resolução. |
| [path-strategy.md](./path-strategy.md) | Define convenções de diretórios por SO e estratégias de fallback para Linux, macOS e Windows. |
| [resolver.md](./resolver.md) | Define a ordem exata de resolução e a cadeia de fallback para cada Virtual Path. |
| [validation.md](./validation.md) | Valida que os Virtual Paths resolvidos apontam para locais existentes, acessíveis e com estrutura correta. |
