# Session: API Governance Standards

## Objective
Define organizational API governance standards for REST and GraphQL APIs.

## Decisions
- OpenAPI 3.1 mandatory for all REST APIs
- Semantic versioning for public APIs
- 6-month deprecation period for breaking changes
- Rate limiting required on all endpoints (1000 req/min default)
