# ADR-003: Multi-Runtime Plugins

## Decision: 4 Plugin Runtimes

| Runtime | Isolation | Performance | Use Case |
|---------|-----------|-------------|----------|
| Go Native | Low | Best | Trusted first-party |
| WASM (wazero) | High | Good | Third-party, sandboxed |
| External Process | Highest | Moderate | Any language |
| SharedLib (.so/.dll) | Medium | Good | Perf-critical C/Rust |

**Plugin manifest**: YAML with id, version, runtime, permissions, hooks, config_schema, checksum.
**Status**: Accepted.
