# ADR-007: Frontend Architecture

## Decision: Next.js 15 + 14 Design Decisions

| Decision | Choice |
|----------|--------|
| Framework | Next.js 15 (App Router) |
| UI Library | Shadcn/UI (Radix + Tailwind) |
| Server State | TanStack Query v5 |
| Client State | Zustand (auth store) |
| Forms | React Hook Form + Zod |
| Auth | JWT with refresh rotation |
| Bundling | Turbopack (dev), custom webpack (prod) |
| Architecture | Feature-based (12 modules) |
| Accessibility | WCAG 2.2 AA+ |
| Testing | Vitest + React Testing Library + Playwright |
| Storybook | 8+ component stories |
| ISR | Incremental Static Regeneration for dashboard |
| CSRF | Double-submit cookie pattern |
| Deployment | Multi-stage Docker (Go + Node) |

**Routes**: 17 (auth + dashboard + admin).
**Status**: Proposed (implemented in Phase 0-4).
