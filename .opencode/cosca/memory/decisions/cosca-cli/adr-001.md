# ADR-001: Layered Go Architecture

## Decision: 5-Layer Go Architecture

| Layer | Components |
|-------|-----------|
| CLI | Cobra, 34+ commands |
| Runtime API | Event bus, state machine, lifecycle |
| Subsystem | Knowledge, Memory, Discovery, Plugins, Editors |
| Infrastructure | SQLite, Cache, Watcher, Logging, Metrics |
| Providers | LLM, Embedding, MCP transport |

**Key choices**: Go 1.22, Cobra CLI, SQLite FTS5+vector, zerolog, Viper config, YAML+env.
**Alternatives rejected**: TypeScript (runtime dep), Rust (learning curve), Python (performance).
**Status**: Accepted.
