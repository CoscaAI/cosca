# ADR-1825: Create Performance Chief

**Status**: Accepted
**Deciders**: Chief AI Platform Architect
**Date**: 2026-07-23
**Tags**: organization, chief, v3.0, enterprise

## Context
The Cosca framework needed to expand its organizational coverage to include enterprise domains that were previously uncovered or inadequately covered by existing chiefs.

## Decision
Create the Performance Chief role as a first-class department in the Cosca organizational structure, with dedicated SKILL.md, specialists, and council representation.

## Rationale
Performance optimization requires dedicated focus and tooling. Previously handled ad-hoc by individual teams, causing inconsistent performance standards. A dedicated Performance Chief establishes organization-wide performance SLOs, benchmarking, and optimization programs.

## Alternatives Considered
1. Extend Monitoring Chief scope: Monitoring is observation, not optimization. 2. Distribute to all Chiefs: Lacks coordination and standards. 3. Dedicated Performance Chief: Centralized standards with distributed execution.

## Decision Outcome
Create dedicated Performance Chief with:
- Reports to: as defined in ORGCHART.md
- Specialists: as defined in departments/performance/SKILL.md
- Council representation: as defined in COUNCILS.md

## Consequences
- Clear ownership for the domain
- Dedicated focus and accountability
- Better cross-department coordination through council representation
- Increased framework size (14 new departments)

## Compliance
- All new departments follow CONVENTIONS.md format
- All departments have AGENT_DNA.md-compliant contracts
- All departments have council representation
