# Compliance Framework Overview

## Active Compliance Standards

## Data Classification
- Public: Marketing materials, public documentation
- Internal: Internal docs, non-sensitive configs
- Confidential: Customer data, business logic

## Data Retention Policies
- User data: 7 years after account closure (GDPR)
- Audit logs: 3 years (SOC2 requirement)
- Session data: 30 days
- Backups: 90 days daily, 1 year weekly
