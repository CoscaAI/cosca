### 2026-08-04 — Idempotent memfd lifecycle cleanup
| Field | Value |
|-------|-------|
| **Technique** | Once-guarded raw FD cleanup |
| **Task** | Fix flaky jail memfd and AppArmor TempDir tests under the race detector |
| **Outcome** | success |
| **Level** | 3 |
| **Tags** | #memfd #file-descriptors #cleanup #race-detector |
| **Learned** | A cleanup callback owning a raw descriptor must be safe to invoke more than once. A second close can target an unrelated descriptor after FD-number reuse, causing both the intended ReadFile assertion and unrelated TempDir cleanup to fail. `sync.Once` preserves first-cleanup semantics and prevents descriptor reuse corruption. |
