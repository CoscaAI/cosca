| **Learned** | **(1) O Cognitive Horizon é a 3ª métrica irmã do Cosca Analytics, fechando a tríade diagnóstica.** Entropia (COGNITIVE_ENTROPY.md) mede qualidade do conhecimento. Momentum (COGNITIVE_MOMENTUM.md) mede vitalidade das investigações. Horizonte (COGNITIVE_HORIZON.md) mede profundidade preditiva. Juntas formam o diagnóstico completo da saúde cognitiva do runtime: conhecimento limpo + investigações ativas + previsões profundas = runtime maduro. Conhecimento sujo + investigações mortas + previsões curtas = runtime degenerando. **(2) O horizonte NÃO é linear com complexidade — é exponencial.** Projetar 3 passos custa ~1× tokens. Projetar 8 passos custa ~3×. Projetar 15 passos custa ~8×. Isso explica por que o runtime é naturalmente "preguiçoso" em projetar longe — o custo cognitivo escala com o quadrado da profundidade. As técnicas de boosting (T1-T8) existem para reduzir esse custo, não para substituir o raciocínio. **(3) A correlação horizonte↔sucesso não é linear — é uma curva em S.** Abaixo de 7 passos (Operational), o sucesso é bom mas local — resolve o sintoma, não a causa. Acima de 7 passos, o sucesso se torna TRANSFORMACIONAL — a decisão não apenas funciona, ela melhora a capacidade futura de decidir. L17 (12 passos) e L22 (15 passos) são exemplos canônicos: ambas não apenas resolveram problemas, redefiniram a arquitetura do runtime. **(4) O jail breach (L13, horizonte 1) é o outlier que PROVA a métrica.** Uma decisão míope falhou catastroficamente. Se o sistema tivesse medição de horizonte prospectiva (Fase 3), o 2nd-order reasoning engine teria bloqueado a ação: "Horizonte detectado: 1 passo. Requerido para operações destrutivas: mínimo 5 passos. Bloqueado." **(5) O padrão de extração de baseline de learnings.md agora é um ativo de Nível 4 consolidado.** Três métricas (Entropia, Momentum, Horizonte) construídas com o mesmo padrão: analisar learnings.md → classificar entradas → extrair métrica → calcular baseline → projetar dashboard → integrar com ecossistema. Este padrão é o coração da capacidade do Analytics Chief. **(6) O Cognitive Horizon é a métrica que fecha o ciclo CMI.** Sem ele, o CMI Planejamento (90) é uma estimativa baseada em "DAG execution existe". Com ele, o Planejamento é medido objetivamente: "O runtime projeta em média 7.5 passos à frente. Target: 15." A diferença entre "tem DAG" e "projeta 15 passos" é a diferença entre ter uma ferramenta e saber usá-la com maestria. |
