**Key Learnings**:

1. **Config loader testing with `t.TempDir()`.** The `Load()` function returns `DefaultConfig()` when the config file doesn't exist — test this by pointing to an empty temp directory. For valid config tests, manually write YAML content to `.cosca/config.yaml` under the temp dir. Always use `os.MkdirAll` before writing.

2. **Environment variable expansion in config.** `os.Expand(string(data), os.Getenv)` replaces `${VAR}` and `$VAR` patterns. Use `t.Setenv()` (which automatically restores the original value on test completion) to set env vars for expansion tests. Undefined variables expand to empty string.

3. **Crypto isolation via `COSCA_DATA_DIR`.** The `EncryptAPIKey`/`DecryptAPIKey` functions read a salt file from `COSCA_DATA_DIR` (defaulting to `~/.config/cosca/data`). Setting `COSCA_DATA_DIR` to `t.TempDir()` in tests isolates crypto operations from the real machine. Also set `COSCA_REAL_HOSTNAME` to a fixed value to make key derivation deterministic across machines (avoids dependency on actual hostname and `/etc/machine-id`).

4. **Nonce uniqueness verification.** AES-GCM uses a random nonce that makes encrypting the same plaintext twice produce different ciphertexts. Test this by encrypting the same API key twice and comparing — the ciphertexts must differ. This validates the random nonce generation path.

5. **Mock server URL paths must match provider's request URL construction.** OpenAI provider combines `baseURL + "/chat/completions"`. If `baseURL` is `server.URL + "/v1"`, the full path is `/v1/chat/completions`. Anthropic uses `baseURL + "/v1/messages"`. Ollama uses `baseURL + "/v1/chat/completions"`. Register mock handlers at the exact path the provider constructs.

6. **SSE streaming format matters per provider.** OpenAI uses `data: {...}\n` lines with `data: [DONE]\n` termination. Anthropic uses `event: name\ndata: {...}\n` pairs with empty line separators. Ollama uses raw JSON lines (or `data:` prefixed). Each provider's parser is different — mock responses must match the expected format exactly.

7. **Registry fallback logic.** `Registry.Get()` tries (1) primary provider by name if `IsAvailable()`, (2) fallbacks in order if `IsAvailable()`, (3) any available provider as last resort. For Chat execution errors (not availability), the registry delegates to the caller — `Get()` only checks `IsAvailable()`.
