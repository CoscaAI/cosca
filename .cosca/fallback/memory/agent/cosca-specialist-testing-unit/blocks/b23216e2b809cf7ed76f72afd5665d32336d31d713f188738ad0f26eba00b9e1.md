| **Learned** | When testing subprocess communication via exec.Cmd (stdin/stdout NDJSON), the re-execution pattern requires: (1) TestMain with env var sentinel, (2) fake server reading stdin + writing stdout, (3) `os.Args[0]` as command with `nil` args, (4) env vars passed through `cmd.Env` for configuration. A mutex deadlock was found: `Connect()` held `c.mu` while calling `initialize()` → `sendRequest()` which also acquired `c.mu` (sync.Mutex is not reentrant). Fix: release `c.mu` before the handshake. Goroutine dump via `-test.timeout` was essential for diagnosis. |
