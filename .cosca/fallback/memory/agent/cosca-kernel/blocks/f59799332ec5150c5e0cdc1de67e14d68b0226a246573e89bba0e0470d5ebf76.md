| **Learned** | **(1) Cosca já tem tracing alinhado com OpenTelemetry!** `internal/trace/trace.go`: TraceID, Event, CausalGraph, DetectDivergence. Mapeamento direto: Cosca Event ↔ OTel Span, Cosca CausalEdge ↔ OTel Links. O que falta: SpanProcessor pipeline (OnStart/OnEnd hooks), Exporter interface (para enviar a Jaeger/OTLP), W3C propagation (traceparent header entre agentes). **(2) OpenFGA ReBAC modela EXATAMENTE nossa hierarquia.** 4-hop chain: department→agent→skill→resource. Check(user, can_access, resource) resolve via BFS no grafo de relações. Substitui JWT binário por autorização condicional com contexto. **(3) Dapr sidecar é o modelo para abstrair infra dos agentes.** Agentes nunca deveriam saber se state store é Redis ou Postgres. Um cosca-agent-runtime sidecar expõe APIs padronizadas (State, Pub/Sub, Secrets, LLM) em localhost. Providers plugáveis via YAML. Resiliency declarativa. **(4) OpenHands event-sourced loop vs nosso pipeline linear.** OpenHands: agent.step() itera (observe→decide→act→observe), estado está no EventLog imutável. Cosca: pipeline linear de uma passada. Para tarefas complexas, o loop iterativo com tool contract tipado (Action→Observation Pydantic) é superior. **(5) Tool contract tipado é melhor que descritivo.** OpenHands: Action/Observation Pydantic → schema JSON auto-gerado para LLM. Cosca: SkillTool com Name+Description string. Schema auto-gerado elimina prompt drift. **(6) Security analyzer como middleware entre LLM e tool execution.** OpenHands avalia risco (baixo/médio/alto) ANTES de executar cada tool. Cosca: permissão declarada no plugin, não por ação. **(7) Condensation como subsistema dedicado para contexto longo.** Rolling-window + summarization via LLM barato quando event count > threshold. Cosca: MAG + EmbedCache, sem condensação explícita. **(8) A arquitetura desejada pelo conselheiro: Desired State → Reconciler → Runtime → Actual State.** Esse é exatamente o padrão Kubernetes/ArgoCD que extraímos (L166, L167). O Cosca como reconciler contínuo, não executor de tarefas pontuais. |
