| **Learned** | **(1) O package name dos stubs gRPC do Cosca é `cospb` (go_package `.../pb;cospb`), não `pb` — importar com alias `pb ".../api/grpc/pb"` ou usar `cospb.`.** **(2) Build Wails sem CLI funciona: `go build -tags webkit2_41` + `go:embed all:frontend/dist`; o CLI só é necessário para `wails dev` (HMR) e para gerar `frontend/wailsjs/` — que NÃO são obrigatórios se o frontend acessar `window.go.main.App.*` direto.** **(3) `modernc.org/sqlite` (pure-Go, sem CGO) é o driver SQLite certo para Wails desktop — portátil, sem gcc.** **(4) Event sourcing + entity-store: eventos imutáveis append-only em memória + hook de persistência SQLite é o padrão que casa auditabilidade (seção 22) com simplicidade.** **(5) A regra epistêmica é código, não comentário: `Promote()` rejeita HYPOTHESIS→VERIFIED sem evidência e REFUTED é terminal — o sistema literalmente não consegue "inventar fato".** **(6) Hidden oracle sem vazamento: o `FunctionOracle.Validate` compara em todos os pontos escondidos e só devolve VALID/INVALID + contagem; `CheckAt(x)` devolve só bool — o agente e o refuter nunca veem f(x).** **(7) Bug de ordem de construção: montar o relatório ANTES da fase de verificação perde os campos preenchidos depois — sempre construir o relatório final POR ÚLTIMO, passando os resultados de cada fase como parâmetro.** **(8) Delegar o kernel não significa não implementar: para projeto novo bem definido, o kernel escreve o núcleo (domínio+contratos+loop) para garantir coerência, e usa subagents para partes isoladas.** |
