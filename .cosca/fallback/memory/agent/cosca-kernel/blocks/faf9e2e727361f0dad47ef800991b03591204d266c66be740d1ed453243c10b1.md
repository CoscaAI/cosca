| **Learned** | **(1) O gargalo do lip sync é 90% multiplicação de matrizes na inferência ONNX — e aí Tensor Cores da NVIDIA mudam o jogo: 4ms/frame (TensorRT) vs 15ms/frame (ROCm). A diferença não está nos TFLOPS brutos (26.5 vs 28, quase iguais), mas na aceleração dedicada de matrizes.** **(2) TensorRT com engine cache (que o FaceFusion já implementa nativamente) compila o ONNX para instruções nativas da GPU — primeira execução lenta (compilação), execuções seguintes 2-3× mais rápidas. `trt_engine_cache_enable: True` + `trt_builder_optimization_level: 4`.** **(3) VRAM não é o limitador: o pipeline usa ~3-4 GB dos 12/16 GB disponíveis. O limitador é a arquitetura de compute. A RX 6700 XT tem 384 GB/s de bandwidth (mais que a 5060 Ti com 288 GB/s), mas perde porque ROCm não usa aceleração de matriz otimizada como CUDA.** **(4) Com RTX 5060 Ti + TensorRT, lip sync é 3.75× mais rápido que tempo real (8 min para 30 min de vídeo) — viabiliza live streaming com avatar sincronizado. Com ROCm é 1.36× (22 min para 30 min) — ainda viável para batch, mas não live.** **(5) A RX 6700 XT precisa de `HSA_OVERRIDE_GFX_VERSION=10.3.0` (gfx1031→gfx1030) — mesmo hack do Ollama (L61). A RTX 5060 Ti funciona out-of-the-box com `onnxruntime-gpu` (CUDA incluso).** |
