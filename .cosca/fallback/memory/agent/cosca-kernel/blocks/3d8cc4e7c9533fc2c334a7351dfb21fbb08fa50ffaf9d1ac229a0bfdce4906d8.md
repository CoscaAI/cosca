| **Learned** | **(1) O padrão "uma ferramenta = um comando global" precisa de 4 peças: registro (internal/tools), launcher cobra (internal/cli), admin-bypass (fora da jaula + gate de integridade) e auto-build com instalação atômica (temp+rename). O desktop é a referência para todas as ferramentas futuras.** **(2) Auto-build por mtime: comparar o binário instalado contra o MAIS NOVO source (.go/.tsx/.ts/.css) — robusto, zero hash. O walker precisa pular node_modules/.git/build ou cada npm install dispara rebuild.** **(3) Launcher GUI NÃO pode passar pela jaula nem pelo gate de memória: adicionar a `isAdminCommand()` E a `integrityGateBypass()` (o gate de memória roda ANTES do auto-jail e recusa se o cwd tem .cosca/ com manifesto ausente/divergente — launcher não carrega memória, deve bypassar).** **(4) `COSCA_WORKDIR` é o contrato de abertura por pasta: o engine do desktop honra a env antes do Getwd (verificado em engine.go) — o launcher só precisa setar env + chdir.** **(5) Warning SECURITY com "Reason: " vazio = comando nem existe (auto-jail roda antes do cobra resolver o comando e o bwrap falha em silêncio) — sintoma de comando ausente, não de jaula quebrada; bwrap manual funciona, o pre-flight interno falha sem stderr.** |
