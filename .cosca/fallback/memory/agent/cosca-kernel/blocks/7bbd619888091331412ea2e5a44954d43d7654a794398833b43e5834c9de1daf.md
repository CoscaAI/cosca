| **Technique** | Level 4 — portar 7 padrões do COSCA NODE para o domínio do Neural Link: **(1)** Event Model: `eventstore.Event` ganha `EventID` (hex 12 bytes crypto/rand) + `CausationID` + `Severity` (mapeada por tipo: INCIDENT=critical, HALT=error, refuted=warning). **(2)** Causação encadeada: helper `engine.emit()` — cada evento aponta pro anterior (`AppendWithCausation`), `lastEventID` encadeia a linha cognitiva. **(3)** `internal/causal`: `Chain(events, eventID)` segue `CausationID` pra trás até a raiz (visited anti-ciclo), inverte pra ordem raiz→alvo — o "WHY?". **(4)** `internal/replay`: `SnapshotAt(events, at)` faz fold dos eventos ≤ T em um resumo (testadas/refutadas/confirmadas/solução) — time travel determinístico. **(5)** `internal/stream`: Hub pub/sub (canal buffer 256, publish não-bloqueante) + endpoint SSE `/events` com flush inicial `": connected"` (sem ele o EventSource não abre até o 1º evento). **(6)** Endpoints `/timeline`, `/causal?event_id=`, `/snapshot?at=`, e `/runs` agora inclui `store.ListRuns()` (read-back da persistência — fecha o gap write-only do L254). **(7)** Frontend: seção "Observabilidade Cognitiva" — feed ao vivo (EventSource) + painel Causal (clique num evento → cadeia). |

| **Learned** | **(1) Padrões de projeto são portáveis entre projetos da família: o "grafo é um FOLD sobre eventos" + `correlation_id`/`causation_id` do COSCA NODE viraram, no Neural Link, `EventID`/`CausationID` + `SnapshotAt` — o mecanismo muda, o princípio é o mesmo.** **(2) Causação é a fundação de tudo observável: sem `CausationID` no Event Model, o "WHY?" é impossível — por isso foi o PRIMEIRO passo, não um enfeite de UI.** **(3) O event store já tinha `Subscribe` (notificação síncrona no Append) — o stream SSE reusou isso em vez de criar um barramento novo: `a.events.Subscribe(func(ev){ a.hub.Publish(ev) })`. A infraestrutura já existia, faltava a fiação.** **(4) SSE sem flush inicial é "conexão invisível": o handler Go buferiza headers até o 1º Write — um `: connected\n\n` + Flush antes do loop é o que faz o EventSource abrir na hora.** **(5) `pkill -f "bin/cosca-neural-link"` mata a PRÓPRIA shell (o padrão casa com o wrapper `/bin/bash -c ...`); o caminho ancorado `pkill -f "^\./bin/cosca-neural-link"` só mata o binário. Mais uma variante do footgun de processo do L251/L252.** **(6) Read-back da persistência (ListRuns) fecha o gap "write-only" do L254 — o `lab.db` agora serve a `/runs` com histórico real, não só grava.** **(7) O binário Wails exige as tags `production,webkit2_41` (não só `webkit2_41` como o README dizia) — sem `production`, o stub `app_default_unix.go` compila e retorna "will not build without the correct build tags" em RUNTIME. Mais um bug de doc encontrado ao rodar de verdade.** |
