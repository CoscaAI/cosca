| **Learned** | A SEGUNDA REGRA DE OURO (mesmo nível da primeira): NENHUMA EVIDÊNCIA PODE ALTERAR O PRÓPRIO MECANISMO QUE DETERMINA SE ELA É VÁLIDA. O perigo: Probe X → "sou confiável" → Evidence X → "Evidence X é válida" → Capability=VERIFIED — o próprio componente se certificou (auto-validação). O correto: OBSERVER (produz evidência) → VALIDATOR (julga a evidência, SEPARADO) → CAPABILITY STATE. OS 10 PRINCÍPIOS DO F7: (1) NÃO PROMOVER SEM NOVA EVIDÊNCIA (L324). (2) NÃO VALIDAR A PRÓPRIA VALIDAÇÃO — observador e validador separados. (3) PROVENANCE É IMUTÁVEL — evidência registrada (evidence_id/source/collector/environment/timestamp/raw_hash) NUNCA é editada; se mudou: Evidence #41 → INVALIDATED → Evidence #58 (nunca "editar"). (4) O PASSADO NUNCA REEsCREVE O PRESENTE — memória histórica gera CANDIDATO À REVALIDAÇÃO, nunca estado atual. (5) FALHA TAMBÉM É EVIDÊNCIA — probe AVX2→FAIL deve ser REGISTRADO (capability/result=failed/environment/timestamp/reason), não descartado — impede repetir eternamente experimentos que já falharam (conecta com L316 memória experimental). (6) UNKNOWN É ESTADO DE PRIMEIRA CLASSE — "não sei" é epistemologicamente mais correto e mais seguro que false; não forçar true/false. (7) EVIDÊNCIA PROPORCIONAL AO IMPACTO — listar diretório (low impact → evidência simples) vs executar código/alterar sistema/publicar/acessar rede (high impact → múltiplas evidências + contexto + política + revalidação + autorização). (8) DETECTOR ≠ AUTORIDADE — o detector diz "encontrei X"; o F7 decide "que tipo de conhecimento isso constitui?"; a política decide "pode ser utilizado?". (9) CAPABILITY ≠ PERMISSION (L324). (10) O SISTEMA DEVE PROVAR QUE NÃO SABE — não só "Cosca sabe X" mas "Cosca NÃO possui evidência suficiente para X" com WHY_UNKNOWN: not_observed / inaccessible / probe_failed / stale / conflicting_evidence / environment_mismatch / insufficient_authority — transforma UNKNOWN em algo EXPLICÁVEL, não um buraco. A mais poderosa: um sistema cognitivo auditável explica não só as certezas, mas também as INCERTEZAS. |
