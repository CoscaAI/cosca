# L348 — Analise de Valor de Informacao: vecs16 vs deduplicacao

## Contexto (campanha performance, apos FASES 3/7/8)
O Don pediu: NAO implementar ainda. Analise cientifica de prioridade de
experimento: A) slab vecs16 vs B) caracterizar deduplicacao do corpus.
Regra: nao otimizar o que nao foi caracterizado; reduzir incerteza primeiro.

## Estado do conhecimento (classificado)
MEASURED 34% duplicatas (13.914 vetores / 9.184 distintos, escopo: este
corpus) · 44.7% quase-empates no oracle top-50 · int16 26.28 Mvec/s e
recall@10 0.984 SINTETICO · int8 producao jaccard 0.82 NDCG 0.90 ·
cache_budget 80MB (profile, nao garantia).
UNKNOWN causa das duplicatas · impacto real no RAG · relacao com 48.621
orfaos sem vetor (re-embed pendente) · recall real do int16.
HYPOTHESIS duplicatas degradam o ranking (causa dos quase-empates).
DECISION anteriores (int8 default, cache_budget) sao REVISAVEIS.

## Resultado da analise (VOI)
B > A em valor de informacao por esforco:
- A (vecs16): risco medio (3 slabs = +40% RAM; 62k int16 = 95.7MB ~= L3,
  risco de perder regime cache); 3 hipoteses; impacto medio-alto mas nao
  ataca a causa estrutural; o recall REAL do int16 e testavel por analise
  read-only (2-3h) SEM implementar o slab.
- B (dedup): risco baixo (read-only); 5 hipoteses; incerteza muito alta
  (maior espaco de reducao); informa o re-embed pendente (48.621 orfaos);
  melhora jaccard/NDCG para TODAS as representacoes.
- O int16 ordena melhor os quase-empates mas nao os remove: otimizar
  sintoma cuja causa nao foi caracterizada.

## DECISION
Executar B (caracterizacao dedup: hash de conteudo x vetor x documento,
diversidade do top-10, orfaos duplicados, simulacao de remocao) + o
sub-experimento de A (recall real do int16 via score16 em Go sobre vetores
reais). Meio dia, read-only. Implementacao (slab ou dedup em producao)
SOMENTE apos os dados. Alternativas documentadas (Alt1: vecs16 ja; Alt2: so B).

## Metricas de sucesso/falha (contrato)
A: jaccard>=0.90 e NDCG>=0.95 = H confirmada; <0.85 = duplicatas dominam.
B1: >=80% duplicatas com conteudo identico no mesmo doc.
B2: top-10 com <8 chunks unicos = respostas repetidas.
B3: >=20% dos orfaos duplicam vetores existentes.
B4: remocao melhora jaccard +0.05 e NDCG +0.03.
