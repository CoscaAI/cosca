| **Learned** | (1) O grafo universal NÃO está pronto só com nodegraph + media isolados — falta a PONTE (Executor). O padrão é: engines expõem funções puras; o Executor implementa a interface nodegraph.Executor e decide o mapeamento type→função + resolução de input. (2) Convenção de fluxo clara é metade do design: nó fonte devolve path; nós de processo devolvem o caminho de saída (encadeiam); nós de metadados devolvem struct tipada. Sem essa convenção o grafo não encadeia. (3) Cache por assinatura é IN-MEMORY por design — a persistência cross-run é responsabilidade do checkpoint/resume (§40), não do cache. (4) Parsing de params map[string]any → structs tipadas precisa tratar JSON []any (não só []string) — json.Unmarshal produz []any. (5) Wire mínimo no CLI (dispatcher: media executa, resto passa direto) preserva o comportamento antigo e destrava o real sem quebrar nada. |
