| **Learned** | **(1) Binance Futures API é extremamente bem documentada e estável: REST em fapi.binance.com, WebSocket em fstream.binance.com, 10+ endpoints públicos sem autenticação.** Paper trading não precisa de API key — todos os dados de mercado são públicos. **(2) WebSocket streams combinados (multiplexed) são o jeito certo: `/stream?streams=btcusdt@aggTrade/btcusdt@kline_1m/btcusdt@depth20` → um único socket TCP com todos os dados, em vez de 5 sockets separados. Economiza recursos e simplifica reconexão.** **(3) O calculador de position sizing precisa considerar alavancagem no cálculo do risco: com 5x, um stop de 2% vira 10% de P&L na posição. O RiskManager atual subestima isso — a fórmula correta é `risco_total = risco_por_trade × alavancagem`. O Don precisa ajustar o RISK_PER_TRADE para 0.4% se quiser risco real de 2% com 5x.** **(4) Streamlit é a plataforma ideal para dashboards de trading em Python: state management nativo (session_state), componentes reativos, plotly integration nativa, e deploy trivial. Para produção SaaS multi-usuário, FastAPI + React seria mais escalável, mas para operação individual ou time pequeno, Streamlit entrega 90% do valor com 10% do esforço.** **(5) O scoring multi-indicador (-10 a +10) funcionou bem no design: RSI (±3), MACD crossover (±2), Bollinger touch (±2), MA cross (±2), volume confirmation (±1). A soma desses fatores captura confluência de sinais — um sinal só de RSI (score 3) é BUY, mas RSI + MACD + BB (score 7) é STRONG_BUY. Isso evita falsos positivos.** **(6) PEP 668 do Python 3.12+ bloqueia `pip install` fora de venv por segurança — `--break-system-packages` existe mas é perigoso. O padrão correto é `python3 -m venv .venv && source .venv/bin/activate && pip install -r requirements.txt`. O Makefile já está configurado pra isso.** **(7) A API da Binance migrou de github.com/binance-exchange para developers.binance.com (docs) e github.com/binance/binance-spot-api-docs (spot). Futures: developers.binance.com/docs/derivatives/usds-m-futures. As bibliotecas python-binance e ccxt são boas mas desatualizam — requests puro + websocket-client dá mais controle e zero dependência de manutenção externa.** |
