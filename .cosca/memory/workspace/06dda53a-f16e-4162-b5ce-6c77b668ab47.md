REGRAS DE CASA (política permanente, aprovada pelo Don 2026-09-02) após travamento recorrente de execução no Windows:
1. NUNCA subir processo para teste sem antes verificar que a porta alvo está livre (Get-NetTCPConnection antes de Start-Process).
2. Para matar processo de teste, SEMPRE usar `taskkill /PID <pid> /T /F` (mata a árvore inteira — go run deixa o binário filho vivo, Stop-Process mata só o pai e o filho fica órfão segurando a porta).
3. Preferir executar comandos via o sandbox gate (que usa processutil.Run com Job Object + idle timeout 120s + hard timeout 30min) em vez de Start-Process manual.
4. Ao fim de qualquer smoke test que subiu API/worker, limpar TODOS os processos do binário (Get-Process por nome) além do PID pai.
Sintoma típico de órfão: execução "trava e não sai mais", delegações subsequentes presas, porta ocupada por PID antigo.
