DOGMA (ordem do Don) — CONTINUIDADE SEMÂNTICA DE CAPACIDADES. CAPACIDADE ≠ PROVIDER. NUNCA escolher primeiro o modelo; escolher primeiro a CAPACIDADE, depois SENSORES, depois EVIDÊNCIA (gate). Cadeia: CAPABILITY → implementações nativas (sensores locais) → Observation {type, content, confidence, source, epistemic, timestamp, trace_id} → GATE de evidência → se suficiente RESOLVE local, se insuficiente/contraditório ESCALA (VLM/LLM externo). VLM é ESCALADA, não identidade da capacidade. Adicionar provider novo NUNCA altera o caminho primário (regra contra regressão; provider é escalada, não substituição automática). Contradição preservada como evidência — não descartar observação porque outra parece melhor; escalar. ex: 'visão' = capability com múltiplas implementações (WinRT OCR, tesseract OCR, detector CLIP/SAM2/GroundingDINO/Depth, métricas visuais, composição multimodal) + VLM externo [ESCALAÇÃO]. Sanidade: 'como analisa imagem?' → deve citar capacidades nativas + gate de evidência, NÃO 'uso VLM externo'. Memória: preservar papel de cada ferramenta na arquitetura, não só que ela existe.
