Padrão arquitetural extraído do repositório MIT "Osiris" (github.com/simplifaisoul/osiris) — proveio de mineração manual em 2026-09-04, avaliado junto ao Don.

PRINCÍPIO-OURO (estado epistêmico tri-estado, sherlock.ts): nunca afirmar um booleano que não pode ser provado. Veredito de observação deve ser um tipo de primeira classe com 6 estados: FOUND, NOT_FOUND (ausência provada), BLOCKED (recusou -> não sei, NÃO é ausência; 401/403/407/429/451/503), INCONCLUSIVE (soft-404: site também reporta um username de controle aleatório como presente -> não confiável), SKIPPED, ERROR (motivo explícito). Calibração com DOIS controles independentes (um só deixa soft-404 escapar quando o controle é rejeitado — Roblox/WordPress passaram num, cairiam no outro).

LIÇÃO META (campanha 001): o padrão é SIMÉTRICO e vale para o AVALIADOR, não só para o modelo. Um veredito de eval FAILURE/FALSE_COMPLETION é uma afirmação sobre o MUNDO que o instrumento alega ter observado; se o instrumento foi BLOCKED/INCONCLUSIVE, a conclusão "modelo falhou" é epistemologicamente inválida — mesmo vício de 403 != not_found, aplicado à avaliação. Modelo pode ter acertado e o instrumento lido errado (análogo ao soft-404). Distinguir eixo VERDADE-DO-MUNDO (existe? funcionou?) de eixo OBSERVAÇÃO-DO-INSTRUMENTO (conseguimos observar com confiança?).

PRIMITIVA PROPOSTA: tipo Verdict no núcleo do COSCA como primitiva de evidência de primeira classe (Evidence Layer), ADR-037.

ADOTAR: Verdict tri-estado, single-flight+TTL+stale-on-error, ConcurrencyPolicy, SSRF hardening, Conditional GET+optional(), Prediction Ledger (2ª onda).
