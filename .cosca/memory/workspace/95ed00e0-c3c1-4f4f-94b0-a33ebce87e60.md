Lição de UX/Visual (2026-09-02, estudo do OpenCode TUI): o OpenCode usa layout 'sidebar direita (42 cols) + chat central (scrollbox com padding) + prompt embaixo + footer no RODAPÉ'. Não tem header pesado — a única info no topo é o logo/título sutil. O COSCA Terminal ficou 'feio' porque: (1) 3 linhas de chrome no topo (header+tabBar+breadcrumbs) em vez de 1 linha fina, (2) sidebar só com painéis (não com info da sessão), (3) mensagens sem visual rich (tool call boxes, reasoning blocks), (4) prompt sem estilo clean. Para replicar a mesma pegada: manter a arquitetura Go+bubbletea mas copiar o visual design — sidebar direita com info da sessão, chat com padding generoso, footer no rodapé, app bar fina, messages com tool call boxes e reasoning blocks, theme expandido com 50+ tokens (diff/markdown/syntax). O framework é diferente (solid-js vs bubbletea) mas o design visual é replicável.
