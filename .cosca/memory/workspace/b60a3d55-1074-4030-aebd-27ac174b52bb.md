DECISÃO (Don): O runtime daemon (`cosca serve`) NÃO deve ser iniciado em Windows sem sandbox. O bubblewrap não existe no Windows, e o processo se nega a rodar sem a env var COSCA_ALLOW_NO_ROOT=1 (que roda SEM jaula, opt-in, nunca seguro). O Don optou por manter fail-closed. Operações seguem via bridge MCP (`cosca mcp serve`, PID 736), que funciona sem o daemon HTTP. Nunca subir o daemon em Windows sem autorização explícita do Don.
