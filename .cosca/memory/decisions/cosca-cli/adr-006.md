# ADR-006: Orchestration Implementation

## Decision: 6 Implementation Questions Resolved

1. Chat Provider interface → `internal/chat/` (dedicated package)
2. Hot-reload support → File watcher + registry invalidate
3. Provider registry pattern → `Registry[T]` with lazy loading
4. Pipeline state → Immutable context passed through stages
5. Error handling → Graceful error collection, partial results
6. Streaming → Separate stream pipeline with typed events
**Status**: Accepted.
