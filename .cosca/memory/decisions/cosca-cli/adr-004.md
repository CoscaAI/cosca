# ADR-004: Editor Adapters

## Decision: Adapter Pattern for 9 Editors

Common `Editor` interface → 9 implementations:
OpenCode, Claude Code, Codex, Cursor, VS Code, Neovim, Windsurf, Zed, MCP Generic.

Each adapter handles: detection, setup, context injection, removal, health check.
MCP protocol provides real-time alternative to file-based context injection.
**Status**: Accepted.
