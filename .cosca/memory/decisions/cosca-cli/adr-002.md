# ADR-002: Hybrid Search Engine

## Decision: FTS5 + Vector + Graph Hybrid Search

Three-phase search pipeline:
1. **FTS5** (BM25 ranking, Porter tokenizer) — exact keyword matching
2. **Vector** (sqlite-vec, 128-dim embeddings) — semantic similarity
3. **Knowledge Graph** (adjacency tables) — entity-relationship traversal

**Why SQLite over Elasticsearch**: Zero external deps, local-first, embedded.
**Performance target**: <20ms p50, <100ms p95.
**Status**: Accepted.
