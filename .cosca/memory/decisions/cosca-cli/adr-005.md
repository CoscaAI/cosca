# ADR-005: AI Orchestration Engine

## Decision: Pipeline-Based Orchestration

4-stage pipeline: Context Builder → Router → Executor → Memory.

Integrates: Knowledge Engine, Memory Engine, Agent system, Skills system, Workflow system, LLM Providers.
Routes user intent to correct agent, chains skills, augments with knowledge/memory.
