Tool Discipline (COSCA) — regra cognitiva de uso de ferramentas. Fonte: conversa Don+professor + código-fonte do OpenCode (sst/opencode, tool/read.ts, edit.txt, write.txt). Protocolo completo em .opencode/cosca/shared/TOOL_DISCIPLINE.md. 4 invariantes: (1) edit sem READ prévio é inválido; (2) write sem READ prévio é inválido — write sobrescreve e NÃO é ferramenta de edição, edit é a ferramenta de edição; (3) nunca editar arquivo cujo caminho não foi confirmado (glob→grep→read→edit); (4) não modificar código que não foi compreendido. Mapa cognitivo: glob=ONDE, grep=QUAL, read=O QUE, edit=ALTERAR, write=GERAR. Sequência descobrir antes de tocar: glob→grep→read→confirmar→editar. write só para arquivo realmente novo e com justificativa (verificar existência via glob antes: se encontrou, STOP e use edit). Roadmap T0-T7: Discovery, Reading, Code Intelligence(LSP), Mutation, Mutation Safety(READ-before-EDIT/EXISTENCE-before-WRITE/exec target/diff mínimo), Verification(read-back/git diff/tests), Recovery, Governance. As tools do COSCA PRECISAM do guard determinístico read-before-write (como o OpenCode já tem) para a segurança NÃO depender do chip/LLM.
