## 1. A SOLUÇÃO (conceito)

### Nome de trabalho: **"CLARO"** — seu farol no mundo digital

Baseado nas dores 1+2+4 (sobrecarga, desconfiança, tarefas repetitivas), o
**CLARO** é uma ferramenta pessoal de navegação digital consciente:

### Os 3 pilares (uma dor cada)

| Pilar | Dor que resolve | Como funciona |
|-------|----------------|---------------|
| **Filtra** | Sobrecarga de informação | Resumo inteligente de notificações/mensagens — só o que importa chega |
| **Verifica** | Desconfiança/golpes | Checagem de autenticidade de mensagens/links antes de você agir |
| **Automatiza** | Tarefas repetitivas | Macro pessoal — tarefas simples viram um clique |

### Proposta de valor (1 frase)
> **"Menos ruído, mais segurança, menos repetição — o CLARO devolve seu tempo e sua paz digital."**

### Público-alvo
- Pessoas sobrecarregadas por notificações (profissionais, pais, estudantes)
- Vítimas em potencial de golpes digitais (idosos, menos técnicos)
- Qualquer um que sente que "o celular manda em mim"

### Plataforma
- **Web app + extensão de navegador** (fácil adoção, sem instalação pesada)
- Local-first (privacidade: seus dados ficam com você — alinhado ao COSCA)

## 2. IDENTIDADE VISUAL

### Conceito da marca
O nome **CLARO** = clareza. A identidade reflete **simplicidade + segurança +
calma** — o oposto do caos digital que ele combate.

### Paleta de cores

| Cor | Hex | Uso | Significado |
|-----|-----|-----|-------------|
| **Azul Profundo** | `#1A2A4A` | Fundo principal | Confiança, profundidade, noite calma |
| **Ciano Claro** | `#38BDF8` | Ações/links | Clareza, o "farol", modernidade |
| **Verde Calma** | `#34D399` | Sucesso/segurança | Confiança, "verificado", paz |
| **Âmbar Atenção** | `#FBBF24` | Avisos | Atenção (sem alarme) |
| **Branco Nuvem** | `#F8FAFC` | Texto/fundos | Limpeza, espaço, respiro |

### Tipografia
- **Título**: Poppins Bold — arredondada, amigável, moderna
- **Corpo**: Inter Regular — legível, neutra
- **Slogan visual**: "clareza em um mundo ruidoso"

### Logotipo (esboço)
Um **farol estilizado** dentro de um **círculo** — o farol ilumina através do
caos:

```
        ◯
     ┌───────┐
     │   ✦   │      ← farol/luz central (ciano)
     │  /|\  │      ← feixe de luz
     │ / | \ │
     └───────┘
     C L A R O
  clareza digital
```

### Ícones dos pilares
| Pilar | Ícone | Cor |
|-------|-------|-----|
| Filtra | Filtro (funil estilizado) | Ciano |
| Verifica | Escudo com check | Verde |
| Automatiza | Raio/engrenagem | Âmbar |

## 3. ESBOÇO DA INTERFACE (wireframe conceitual)

```
┌─────────────────────────────────────────────────────────┐
│  ◯ CLARO                      [⚙ Ajustes]  [👤 Perfil] │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Bom dia! Aqui está o seu resumo claro de hoje:         │
│                                                         │
│  ┌─────────────────┐  ┌─────────────────┐               │
│  │ 📩 12 msgs       │  │ 🛡 3 verificadas │               │
│  │ → 3 importantes  │  │ → 2 seguras      │               │
│  │ → 9 silenciadas  │  │ → 1 ⚠ cuidado    │               │
│  └─────────────────┘  └─────────────────┘               │
│                                                         │
│  ✦ [Resumo do dia]      [Verificar mensagem]            │
│  ⚡ [Automatizar tarefa]                                 │
│                                                         │
│  ── Notificações filtradas ──                           │
│  ✓ Banco Central: você tem um comprovante novo          │
│  ⚠ Número desconhecido: "você ganhou um prêmio"         │
│    → [Verificar antes de responder]                     │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### Princípios da UI
1. **Um olhar, um entendimento** — o resumo vem primeiro
2. **Verde = pode confiar, âmbar = cuidado** — sem jargon técnico
3. **Ações em um clique** — verificar, silenciar, automatizar
4. **Calma visual** — muito espaço branco, nada grita
