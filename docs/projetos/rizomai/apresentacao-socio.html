1. Resumo Executivo

O que é o RIZOMAI em 30 segundos

RIZOMAI é uma plataforma API-first que permite publicar, agendar e gerenciar conteúdo em diversas redes sociais simultaneamente — com um único post enviado uma única vez. O nome vem de "rizoma": uma estrutura onde cada ponto conecta com todos os outros, sem centro — exatamente o que fazemos com as redes sociais.

O público-alvo são desenvolvedores, agências e agentes de IA que precisam de acesso programático a múltiplas plataformas (Twitter/X, Instagram, LinkedIn, YouTube, TikTok, Facebook, Telegram, Bluesky, Pinterest, Reddit, Snapchat, Google Business e mais) sem ter que integrar a API de cada rede individualmente — o que hoje exige 16 integrações separadas, manutenção constante e conhecimento profundo de cada ecossistema.

Por que agora

  • O mercado global de gestão de mídia social cresce a dois dígitos ao ano e as ferramentas dominantes (Sprout, Buffer, Hootsuite, Zernio) são caras, em inglês e voltadas ao eixo EUA/Europa.
  • O canal de agentes de IA está nascendo agora — plataformas que oferecem API + MCP (Model Context Protocol) capturam este canal emergente antes dos concorrentes clássicos.
  • América Latina é o oceano azul: nenhuma concorrente relevante fala português, cobra em R$ ou oferece suporte humano local.

A tese em uma frase

"Vendemos infraestrutura de marketing: uma API única para todas as redes sociais,
com preço justo para a América Latina."

2. O Problema

A dor real de quem vive de conteúdo digital

2.1 O custo de integrar redes sociais hoje

Para publicar em 5 redes diferentes, um desenvolvedor precisa integrar 5 APIs distintas, cada uma com: OAuth próprio, regras de rate limit diferentes, formatos de mídia distintos, requisitos de aprovação (review de app), documentação inconsistente e manutenção constante (APIs mudam com frequência). Na prática:

  • 6–12 meses de trabalho de engenharia para uma integração sólida multi-rede;
  • Centenas de horas/ano de manutenção quando alguma plataforma altera a API;
  • Risco de ban para quem usa soluções de automação não-oficiais (scraping);
  • Agências perdem horas gerenciais publicando manualmente rede por rede.

3. A Solução

Como o RIZOMAI funciona

3.1 Conceito central: o fan-out

O cliente envia um único post com uma lista de plataformas. O RIZOMAI se encarrega de publicar em cada uma, com status individual por plataforma:

POST /v1/posts { content: "Olá, mundo! #rizomai", platforms: [twitter, linkedin, telegram] }
↓
twitter: ✅ publicado  |  linkedin: ✅ publicado  |  telegram: ⏳ falhou → retry
↓
Post agregado: "parcial" (publicou 2 de 3) + webhook post.partial

Se uma plataforma falhar, o retry é por plataforma — sem republicar as que já deram certo. Tudo com idempotência: o mesmo post enviado duas vezes não duplica conteúdo.

↓
[ API Gateway: Go — REST /v1, OpenAPI 3.1, Idempotency-Key ]
↓
[ Workers: Go — fila River (PostgreSQL) → fan-out de publicação ]

[ PostgreSQL único — domínio + JSONB ] · [ Cloudflare R2 — mídia (presign 5GB) ]

[ Webhooks HMAC-SHA256 · Billing Stripe (cartão + PIX) · Analytics ]

4.2 Princípios de engenharia (não negociáveis)

  • Idempotência em 2 camadas: Idempotency-Key do cliente + content-hash com dedup de 24h — sem posts duplicados.
  • Webhooks confiáveis: evento com id, assinatura HMAC-SHA256, timeout curto, retry com mesmo id, log de entregas, endpoint de teste.
  • Status por plataforma: cada destino tem seu próprio estado e histórico de tentativas (auditável).
  • Health check de contas: detecção proativa de token expirado/permissão revogada — nunca falha silenciosa.
  • Erros machine-readable: envelope {code, error, details} + rate limits com headers X-RateLimit-*.

5. Modelo de Negócio

Como o RIZOMAI gera receita

5.1 Estratégia de preço (proposta)

Modelo usage-based por conta conectada (validado pelo benchmark Zernio, que abandonou cotas de posts): o cliente paga pelo número de contas sociais conectadas, com preço que cai conforme escala. Tudo incluso: posts ilimitados, analytics, webhooks.

FaixaContas conectadasPreço/contas excedentes
Grátis1–3 contasR$ 0 — para sempre, sem cartão
Growth4–10 contas~R$ 4–8 / conta/mês
Escala11–100 contas~R$ 2 / conta/mês (preço decrescente)
Agência10+ contas + equipe + white-label básicoR$ 49–99 /mês fixo

Valores finais sujeitos a validação com o Don (decisão de rate card pendente).

5.2 Go-to-market (como chegamos ao cliente)

  1. Conteúdo e SEO por plataforma: páginas "/twitter", "/instagram", "/whatsapp" capturam busca por automação social.
  2. GitHub e ecossistema open source: SDKs, exemplos MIT, org verificada — o mesmo caminho que deu 717 followers à Zernio em meses.
  3. Canal de AI agents: servidor MCP + arquivo llms.txt + página "instruction set" — agentes descobrem a API sozinhos (canal emergente, custo baixo).
  4. Comunidade n8n: node de integração para automação low-code.
  5. LATAM como foco: docs PT-BR, suporte humano, preço em R$ com PIX — ninguém no mercado faz isso.
